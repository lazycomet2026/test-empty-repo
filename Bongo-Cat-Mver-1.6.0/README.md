# Bongo Cat Mver (Win7 兼容 / 无 UI 小窗口定制版)

这是一个基于原版 Bongo Cat Mver (v1.6.0) 深度修改的分支版本，专门针对 Windows 7 等低版本系统进行了底层优化。

## 核心修改内容

- **彻底解决 UI 闪退问题**：由于原版在 Win7 下调用 `CatUILauncher.exe` 会导致闪退，本版本已在源码层面直接移除了该死机的 UI 启动逻辑，程序运行极其稳定。
- **强制锁定小窗口**：直接在源码中硬编码了初始化窗口尺寸（350x200），彻底解决了原版启动时画框过大、猫咪被裁切的问题。
- **强制开启桌宠透明置顶**：无需手动进 UI 勾选，打开就是完美的无边框、透明背景小猫咪。
- **新增快捷键实时缩放**：既然没有了 UI，我们加入了新的快捷键。按住 `Ctrl` 加上方向键 `↑` 或 `↓`，即可实时放大或缩小猫咪。

## 编译与下载

本项目已配置 GitHub Actions 自动化构建。如需下载成品 EXE：

1. 点击仓库上方的 **Actions** 标签。
2. 选择最新的构建记录。
3. 在页面底部的 **Artifacts** 区域下载 `BongoCat-EXE` 压缩包。

## 操作说明

- **移动**：按住 `Ctrl` + 鼠标左键拖动。
- **调整大小**：按住 `Ctrl` + 键盘方向键 `↑` / `↓`。
- **退出**：任务栏右下角托盘右键退出。
